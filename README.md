# PokePoker

Front-end de un duelo de tres cartas Pokémon contra la IA. Apostas un objeto del mazo, PokeAPI reparte las cartas y gana el tipo o el ataque mas fuerte. El ganador se lleva los premios.

Rama de este envio: `stage-react-api`.

## Arranque

```bash
npm install
npm run dev
```

- Cartas: [PokeAPI](https://pokeapi.co/)
- Tu cuenta (login y mazo) habla con la API local en `http://localhost:3000`

Demo: `ash@pokepoker.test` / `AshMazo26`
